# Поиск фильмов — Redux Toolkit

Домашняя работа к занятию «Redux Toolkit». Приложение ищет фильмы через OMDb API, показывает подробную информацию и сохраняет избранное в браузере.

## Возможности

- поиск фильмов, сериалов и эпизодов;
- состояния загрузки, ошибки и отсутствия результатов;
- подробная страница фильма;
- добавление и удаление избранных фильмов;
- сохранение избранного в `localStorage` через Redux middleware;
- адаптивный интерфейс.

## Запуск

```bash
npm install
npm run dev
```

При необходимости создайте `.env` и укажите собственный ключ:

```text
VITE_OMDB_API_KEY=your_omdb_api_key
```

## Проверки

npm run format:check
npm run lint
npm run build
